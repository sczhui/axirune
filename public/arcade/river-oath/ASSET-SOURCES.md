# River Oath asset sources

All raster art in this directory was generated for Axirune with the built-in
ImageGen workflow on 2026-08-06. The images are original, contain no extracted
game assets, and were prompted to avoid the character likenesses, level layouts,
symbols, UI, and art direction of *Knights of Valour* / 《三国战纪》 or any other
existing franchise.

| File | Prompt summary |
| --- | --- |
| `river-oath-key-art.jpg` | Three newly invented late-Han-inspired heroes at a storm-lit river fortress; premium stylized 3D realism; no text, logos, existing characters, or franchise motifs. |
| `stage-reedwater.jpg` | An empty rain-soaked reed-marsh causeway with a broad 2.5D combat lane and layered parallax depth. |
| `stage-foundry.jpg` | An empty mountainside bronze foundry with water wheels, crucibles, a clean combat floor, and warm/cool gameplay lighting. |
| `stage-harbor.jpg` | An empty moonlit military harbor with blank sails, wet stone, layered ships, and a readable combat quay. |
| `stage-beacon.jpg` | An empty mountaintop beacon court above clouds at sunrise, composed as a spacious final-boss arena. |

The generated PNG masters remain in Codex's generated-image store. Optimized
JPEG derivatives are committed here for browser delivery.
